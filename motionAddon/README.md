# Motion Addon

プレイヤーの動きを作り直すリソースパック（スクリプトなし）。nextAdventure とは別のアドオン。

## Ver.0.3.3
- **ひじ・ひざ**：腕と脚を上下2つに分けて、プレイヤーのスキンで描く（三人称。一人称の腕はバニラのまま）
- 三人称：歩き・走りのキーフレームのサイクル（ひじの曲げ、ひざの曲げ伸ばし、前傾、体のひねり、上下の弾み）、
  ジャンプ（上りでひざを抱え、下りで伸ばす）、着地（ひざを曲げて沈む）、剣の振り（振りかぶって斜めに切る）、
  素手のパンチ（ひじを引いて構え、まっすぐ突き出す。左手は顔の前で構える）
- 一人称：剣の振り（右上へ振りかぶり、画面の真ん中を通って左下へ切り下ろす）、素手のパンチ（真ん中・奥へ突き出す）、
  走りで持ち物を下げる、ジャンプ・着地の上下
- 剣は `minecraft:is_sword` タグの付いたアイテム、パンチは何も持っていないとき
- 走りは `q.is_sprinting`、または腕・脚の振りの大きさ（`q.modified_move_speed`）が 0.95 を超えたとき

## 体型・スキン
スティーブ体型（太い腕）とアレックス体型（細い腕）の両方に、ひとつのパックで対応する。

関節を使うかどうかは、スキンのモデルの**形**で決める。肩・もも・手（持ち物の位置）の関節の位置を
`q.get_default_bone_pivot` で読み、標準のスティーブ型・アレックス型と同じなら関節を使う（`v.motion_wide` / `v.motion_slim`）。
マーケットプレイスのスキンも、標準の形なら関節が付く。
形が違うスキン（体の形を変えたもの、キャラクタークリエイター など）はスキンの絵の並びも違うことがあるので、
関節を使わずバニラの腕・脚のまま。動き（歩き・走り・剣・パンチ）はそのまま付く。

## しくみ
- アニメーションは、バニラのプレイヤーの root コントローラー（`controller.animation.player.root`）を**同じ ID のまま上書き**して
  （`animation_controllers/motion.player.animation_controllers.json`）、first_person / third_person の状態の中で動かす。
  一人称では、外（scripts.animate）に置いた動きも、別の ID にした写しの中の動きも反映されなかったため
- `entity/player.entity.json`（バニラのプレイヤー）を置き換える。中身は Mojang/bedrock-samples 1.26.50 に
  変数・アニメーション・描き方を**足しただけ**（`tools/build.py` が作る）。同じファイルを置き換える他のアドオンとは一緒に使えない
- 関節つきの腕・脚はマントと同じやり方：別のモデル（`models/entity/motion_limbs.geo.json`）を同じ骨の名前で重ねて、
  別の描き方（`render_controllers/motion.player.render_controllers.json`）で出し、バニラの腕・脚は隠す
- 上腕・ふとももはバニラと同じ骨なので、バニラのアニメーション（弓を引く、盾を構える など）もそのまま効く
- 前腕・すねの骨は、スキンのモデルにある重ね着の骨の名前（`rightSleeve` `leftSleeve` `rightPants` `leftPants`）を使う。
  ゲームはスキンのモデルにある骨の分しか動きを計算しないようで、新しい名前にした 0.2〜0.3 ではひじ・ひざが曲がらなかった。
  重ね着の骨はバニラのアニメーションが動かさない。pivot もスキンのモデルと同じ（肩・ももの付け根）にして、
  ひじ・ひざで曲がるように位置をずらしている（build.py の `joint_follow`）
- 手に持つ物はバニラの腕の rightItem に付く（ひじがない）ので、前腕を曲げたぶん rightItem をひじ中心に回した位置へ動かしている
- 鎧（腕・脚）はバニラの骨に付くので、ひじ・ひざでは曲がらない

## 作り方・確認
- `python tools/build.py [出力先]`：モデル・描き方・アニメーション・player.entity.json を作る。
  数値（キーフレーム）は build.py の `WALK` `RUN` `SLASH_TP` `SLASH_FP` など
- `node tools/preview/render.cjs <出力フォルダ> <three.min.js> <スキンの png>`：確認画像を作る（Playwright と Chromium が必要）。
  Molang を評価して、スキンを貼った人型を three.js で描く。`MOTION_SLIM=1` でアレックス体型のスキンのモデル（alex.png と組み合わせる）
- マイクラの更新でバニラのファイルが変わったら、`tools/vanilla/` を差し替えて build.py を実行し直す

## パッケージ
リソースパックのフォルダを zip にして拡張子を `.mcpack` にする。
